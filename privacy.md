**Données traitées sur votre appareil**

ShaetherLm est une application Windows qui permet de travailler avec des modèles d’IA locaux ou distants. L’application peut traiter les messages, les fichiers et les images que vous lui fournissez, ainsi que la voix lorsque vous utilisez le microphone. Les paramètres, les historiques, les points de reprise et les mémoires enregistrées par l’application sont conservés sur votre appareil. Les clés API sauvegardées sont protégées à l’aide de votre compte Windows.

**Services en ligne**

Lorsque vous utilisez un moteur d’IA local, l’inférence se fait sur votre appareil. Certaines fonctions utilisent le réseau selon vos réglages et les outils que vous lancez.

- Un modèle distant reçoit les messages et le contexte nécessaires à la requête, y compris, selon la tâche, des extraits de documents ou de conversations utilisés pour la mémoire.
- La recherche Web envoie les termes recherchés au fournisseur choisi. La consultation de pages contacte les sites demandés.
- Groq reçoit l’audio soumis pour la dictée ou les images soumises à sa fonction d’analyse. La lecture à voix haute via Microsoft Edge TTS envoie le texte à lire au service de synthèse vocale.
- Si vous activez n8n, les données nécessaires à l’exécution du flux de travail sont envoyées à l’instance que vous configurez. Ce flux peut à son tour faire appel à d’autres services.

Les fournisseurs externes traitent et conservent les données reçues selon leurs propres politiques de confidentialité. Les scripts et programmes externes que vous autorisez s’exécutent avec les permissions de votre compte Windows et peuvent utiliser le réseau.

**Vos choix et vos données**

Vous pouvez choisir le moteur et les services utilisés dans les paramètres, et désactiver les intégrations facultatives. Vous pouvez consulter vos données enregistrées sur votre appareil et les supprimer des dossiers où elles sont stockées. Retirer une mémoire du rappel de l’assistant laisse subsister la conversation source sur le disque. Pour les données déjà envoyées à un service tiers, consultez les options de ce fournisseur.

**Assistance et demandes de confidentialité**

Si vous contactez l’éditeur, votre adresse et le contenu que vous communiquez servent à traiter votre demande et sont conservés le temps nécessaire à son suivi. Pour toute question ou demande concernant vos données personnelles, écrivez à shaetherlm@gmail.com.
